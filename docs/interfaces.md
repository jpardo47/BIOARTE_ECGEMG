# Contratos de integracion v1 (antes de delegar)
## Configuracion y modelos
Unica fuente de defaults: app/config.py AppConfig y FilterConfig; ver campos tipados. JSON config refleja to_dict(), filters anidado, directorios strings. main --config carga AppConfig.load.
app/models.py define SampleBlock(sample_index uint64[N], time_s float64[N], adc int[N,3], sample_rate Hz, simulated bool). Columnas ADC: ecg A0, emg_raw A1, emg_env A2, cuentas 0..1023. time_s comienza 0 y sigue indice/fs preservando huecos; resets del dispositivo deben mantener tiempo monotono y contarse. ProcessedBlock(raw, volts float64[N,3], ecg_filtered, emg_filtered, emg_rms, emg_envelope, emg_env_smoothed V[N], r_peak bool[N], bpm float[N], 0 hasta RR valido). Todas las salidas finitas; bloques vacios aceptados. control(source) admite env/rms/envelope.
Calibration(source, rest_level V, active_level V, simulated, created_at ISO) validate() y normalize(value) estan en models. Modulos no inventaran nombres alternativos.
## Serial y procesamiento (TERRA)
ASCII 230400 8N1: #fs=1000,columns=n,ecg,emg_raw,emg_env\n luego indice,ecg,emg_raw,emg_env\n. Indice uint32 con overflow; aceptar CRLF. Metadata se valida; cuatro enteros exactos, ADC 0..1023. Perdidas por saltos, resets explicitos. Sin datos sinteticos en real.
SerialParser(config:AppConfig); feed_line(line:bytes|str) -> tuple[int,int,int,int]|None; .stats AcquisitionStats; .sample_rate float. Parser mantiene contadores y frecuencia efectiva por reloj monotono (no calcular usando solo indice).
SignalProcessor(config:AppConfig); process(block:SampleBlock)->ProcessedBlock; reset(sample_rate:float|None=None)->None. Cambiar fs reinicia filtros validando Nyquist. Filtros no en GUI.
SerialWorker(config:AppConfig, port:str) y DemoSource(config:AppConfig) heredan QThread. Senales: block_ready(object ProcessedBlock), stats_ready(object AcquisitionStats copia), status_changed(str), error(str). Metodos publicos start() heredado, stop() detiene y espera acotadamente, sin terminar QThread forzosamente. SerialWorker.list_ports() static -> list[str]. SerialWorker abre en run(), flush input, timeout, buffering parcial, desconexion/silencio controlado, siempre emite estado final. GUI Conectar prueba disponibilidad del puerto mediante pyserial (no lee); Iniciar crea worker; Detener para worker; Desconectar libera estado. Demo solo habilitada por --demo; selector no puede activar demo sin bandera.
## GUI (LUNA)
MainWindow(config:AppConfig, demo:bool=False). La GUI orquesta workers por sus interfaces publicas, reinicia al iniciar, cierra worker y grabador al closeEvent; muestra advertencias de errores. Mantiene self.last_block para smoke test; tres plots en self.plots para inspeccion. Fuente demo visualmente marcada; no mezclar calibracion demo/real. Selector de fuentes normalizacion; 5s reposo y 5s activa por tiempo de muestra; progreso; guardado/carga JSON. Cambiar fuente invalida calibracion.
## Grabador/calibracion (LUNA)
DataRecorder(config:AppConfig); start(metadata:dict)->Path CSV; write(block:ProcessedBlock)->None (encola sin bloquear GUI); stop()->None (drena, cierra, reporta fallos); .error str|None y .is_recording bool. Cola acotada: si llena, detener con error visible, nunca perder bloques silenciosamente. Trabajador captura errores de IO.
CSV orden exacto: sample_index,time_s,ecg_adc,emg_raw_adc,emg_env_adc,ecg_v,emg_raw_v,emg_env_v,ecg_filtered,emg_filtered,emg_rms,emg_envelope,emg_env_smoothed,r_peak,bpm.
JSON mismo stem: timestamp ISO, port str, baudrate int, nominal_fs Hz, effective_fs_initial Hz, adc_reference_voltage V, filters dict, normalization_source str, calibration dict|null, mode real|demo, app_version str. GUI crea diccionario completo al start. Recorder asegura timestamp y app_version y no altera campos suministrados. Funciones save_calibration(calibration:Calibration,path:Path), load_calibration(path:Path)->Calibration en data_recorder.py.
## Audio (LUNA)
AudioEngine(config:AppConfig); start(mode:str, music_path:str|None=None, sync_r:bool=False)->bool; update(level:float,r_peak:bool=False)->None; stop()->None; .error str|None; .enabled bool; modos music/generative. Fallos controlados; GUI muestra error y sigue adquiriendo. Metodos publicos level_to_note(level)->int y volume_for_level(level)->float para probar mapeos. Precalcular notas al start, no en serial; canales de notas y latidos separados. Volumen configurable desde GUI, duracion, intervalo minimo, sync siguiente R.
## Errores y desconexion
No excepciones sin capturar en trabajadores. Emitir error y status final. GUI detiene grabacion en fallo/desconexion y permite reconectar. stop idempotente, termina recursos, no deja thread vivo al salir. Stats envian snapshot; no emitir una senal por muestra. Colas/buffers acotados. Cualquier cambio de contrato requiere solicitud en handoff y SOL lo integra tras fase paralela.
